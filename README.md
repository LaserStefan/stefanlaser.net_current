# stefanlaser.net

Personal site of Stefan Laser: Hugo + PaperMod, edited with Sveltia CMS, hosted on
Cloudflare Pages, with new posts sent to Bluesky, Mastodon and LinkedIn.

- Setup and day-to-day use: [SETUP.md](SETUP.md)
- CMS: `/admin/`

Run locally: `git submodule update --init`, then `hugo server` and open http://localhost:1313/.
Sveltia can edit this local folder directly at http://localhost:1313/admin/ (Chrome or Edge:
"Work with Local Repository").

Imported from the Micro.blog archive (394 posts, 529 files) on 28 October 2026. Photos were
stored at max. 2000 px; the full originals remain in the archive repository.
